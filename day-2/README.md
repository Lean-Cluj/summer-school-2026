# Day 2

## Morning session — propositions and the logical connectives

A proof is a term whose type is the statement. Starting from equality, the
session treats the connectives and quantifiers `→ ∀ ∧ ∨ ↔ ∃ ¬`, each in the target (how to
prove it) and in the context (how to use it), then classical logic and the
relation between `Prop` and `Bool`.

[Session page](logic/README.md)

## Afternoon session — calculation and proof principles

Proofs by calculation with rewriting, `ring`, `norm_num` and `calc`;
inequalities and congruences; case analysis and induction; the search tactics
`simp`, `nlinarith`, `grind` and `aesop`; tactic combinators and macros.
