# Collaborative project following a blueprint

We formalize in Lean 4, using Mathlib 4, the following blueprint: https://mihaiancu.github.io/Puzzle/.

The plan is as follows:

1. We warm up by completing [Exercise.lean](Exercise.lean) and [WarmUp.lean](WarmUp.lean).

2. We discuss [the problem](https://mihaiancu.github.io/Puzzle/).

3. We discuss the definitions. See  [SolutionDraft.lean](SolutionDraft.lean).

4. We split into teams to tackle parts of the solution. See the [dependency graph](https://mihaiancu.github.io/Puzzle/blueprint/dep_graph_document.html).

5. We formalize the statements of the results and definitions. You can also follow the [blueprint PDF](https://mihaiancu.github.io/Puzzle/blueprint.pdf).

6. We formalize the proofs of the results.

We will share the work in progress in [Zulip](https://lean-cj-2026.zulipchat.com/).
